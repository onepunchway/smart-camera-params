# 智能相机参数推荐小程序

一款微信小程序：通过**环境感知**（定位、天气、时间/季节）+ **实时取景画面分析**，为手机专业拍摄模式自动生成 ISO、快门、光圈、曝光补偿、白平衡等参数，并给出可解释的推荐理由。面向摄影新手，打开即用、无需登录。

对应开发文档：《智能相机参数推荐小程序 项目开发文档》V1.0（本目录）。当前为 **V1.0 基础版**。

## 快速开始

1. 打开**微信开发者工具** → 导入项目 → 选择本目录（`camera/`）
2. AppID：默认使用测试号（`touristappid`）。建议在 `project.config.json` 中替换为你自己的 AppID（游客模式下调用地埋定位等接口受限）
3. （可选）在 `config/config.js` 中填入**和风天气** API Key，即可启用自动天气感知：
   ```js
   weather: {
     apiKey: '你的Key',        // https://dev.qweather.com/ 免费申请
     apiHost: 'https://devapi.qweather.com',
   }
   ```
   - 开发版密钥默认走 `devapi.qweather.com`；若你的控制台分配了专属 API Host 请对应修改
   - **不填 Key 也能用**：小程序自动降级为"天气估算/手动模式"，核心参数功能不受影响
4. 项目已配置 `urlCheck: false`（等价于详情设置里勾选"不校验合法域名"）。正式发布前需在小程序后台把 `devapi.qweather.com`（或你的 API Host）加入 request 合法域名

## 功能总览（V1.0）

| 模块 | 说明 |
|---|---|
| 主取景页 | 全屏实时取景，帧采样分析（默认1帧/秒，设置页可调），底部悬浮参数栏（ISO/快门/光圈/补偿），双击参数栏锁定，右下角翻转/预设/历史/设置 |
| 环境感知 | 定位 → 和风 GeoAPI 反查城市 → 实时天气（1小时缓存）；时段（黄金/蓝调/正午强光/黄昏/深夜）按经纬度日出日落精确划分；季节自动判定 |
| 参数引擎 | EV 基准 + 画面修正动态加权融合（典型0.6/0.4，偏差>2强制0.2/0.8），ISO优先映射，快门钳制 1/4000~1/30s，残差进曝光补偿（±3EV 步进0.3） |
| 画面分析 | 9×12 分区测光（中心区×2权重）、高光/暗部占比、R/B 比值色温估算（饱和度过高自动锁定环境色温）、3帧平滑、抖动暂停更新、刘海区/纯黑纯白像素剔除 |
| 参数详情 | 每项参数附作用说明与推荐理由；曝光补偿/色温滑块微调；保存为预设 |
| 辅助功能 | 预设管理（增删改查/一键应用）、拍摄历史（快门键拍照存档，上限100条）、设备曝光校准、意见反馈 |

### 降级策略（文档 6.4）

| 场景 | 行为 |
|---|---|
| 相机权限拒绝 | 纯环境参数模式，仅按天气/时间输出参考参数 |
| 定位+天气均不可用 | 纯画面分析模式，基于先验EV12+画面修正计算 |
| 天气请求失败 | 复用过期缓存 → 按时段估算（夜间/日间），界面提示"天气为估算值" |
| 极亮（亮度>240） | 强制最低ISO+最快快门，补偿 -1EV 起步 |
| 极暗（亮度<30） | ISO 压到设备上限 2/3 内，提示使用三脚架 |

## 运行测试

算法层（参数引擎、画面分析、太阳时段、工具函数）为纯 JS，可直接用 Node 跑：

```
node test/run.js
```

覆盖：基础EV、亮度映射、融合权重、EV→参数物理映射（阳光16法则锚点）、极端场景兜底、白平衡融合、EMA/滞回、日出日落精度（北京±20min）、合成帧分析等 44 个用例。页面与 wx API 需在开发者工具中人工验收。

## 与开发文档的实现差异说明

1. **附录B EV对照表未采用**：该表与 EV 物理定义不自洽（如 EV10/f2.8 应为 1/125s，表中为 1/1000s）。按文档 5.1"符合摄影曝光物理逻辑"的要求，实现采用 `EV100 = log2(N²/t)`，与阳光16法则（EV15 → f/16、约1/125s）一致
2. **帧分析不经过 Canvas**：直接对 `onCameraFrame` 的 RGBA ArrayBuffer 做下采样计算，行为一致、开销更小
3. **IP 定位兜底以"手动选择城市"替代**：IP 定位需服务端支持，V1.0 无后端；手动模式（设置页）承担同等降级职能
4. **中心加权均值**：文档 6.2.1 的"中心区域权重加倍"落实在整帧平均亮度上（而不仅分区），分区均值本身不加权
